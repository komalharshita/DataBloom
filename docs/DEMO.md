# 90-second live demo

1. Load DataBloom. Headline: **Turn your data into a story.**
2. Click **Try Demo**. Do not wait for a custom file.
3. Point to Dataset Overview: rows, columns, types.
4. Read one sentence of the executive summary.
5. Show Key Metrics (calculated, not guessed).
6. Open one chart (revenue over time or region comparison).
7. Close with one insight and one recommendation.

Backup if the API key is missing: the demo still works from Pandas evidence.

Optional second beat: upload another CSV and ask “Which region is performing best?”
